# VK WorkSpace Mail Archive

**Локальное резервное копирование и перенос почты VK WorkSpace / Mail.ru в EML и MBOX.**

[Русский](#русский) · [English](#english)

> **Статус: экспериментальный релиз (0.1.0).** Инструмент использует неофициальные HTTP-интерфейсы веб-почты. VK может изменить их работу без предупреждения. Проверяйте результат и держите резервную копию.

## Русский

### Возможности

- Открывает отдельный Chromium через Playwright; пользователь входит в VK WorkSpace вручную.
- Перехватывает авторизованный запрос списка писем в браузере. Токены не записываются в файлы конфигурации и журналы.
- Получает дерево папок и переписки, скачивает оригиналы писем в формате RFC 822 (`.eml`).
- Ведёт локальную базу SQLite для учёта выгруженных сообщений и возобновления работы.
- Формирует MBOX-файлы по папкам для импорта в Thunderbird.
- При HTTP/API 401 или 403 останавливает выгрузку, а не продолжает отправлять заведомо отклоняемые запросы. Уже скачанные EML и SQLite сохраняются.

### Требования

- Windows 10/11 x64.
- Python 3.11 или новее.
- Доступ к VK WorkSpace/Mail.ru в браузере.
- Свободное место на диске под почтовый архив.

### Установка

Скачайте ZIP релиза или клонируйте репозиторий. Откройте PowerShell в каталоге проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

Активация виртуального окружения не требуется. Playwright устанавливает отдельный Chromium; установленный Vivaldi или другой браузер для работы загрузчика не используется.

### Тестовый запуск

Укажите адрес нужного почтового ящика и каталог, в который сохранять архив:

```powershell
.\.venv\Scripts\python.exe mail_archive.py --email user@example.com --out "C:\MailArchive\user" --max-threads 2 --max-messages 3
```

Откроется окно Chromium. Войдите в VK WorkSpace, откройте почту и дождитесь загрузки списка писем. Скрипт перехватит авторизованный запрос и выполнит небольшой тестовый экспорт.

Проверьте несколько EML-файлов и MBOX, прежде чем запускать полную выгрузку.

### Полная выгрузка

```powershell
.\.venv\Scripts\python.exe mail_archive.py --email user@example.com --out "C:\MailArchive\user"
```

При повторном запуске используйте **тот же каталог `--out`**. SQLite-индекс позволит пропустить уже сохранённые сообщения и продолжить работу. Если VK вернул 401/403, войдите в аккаунт заново в открывшемся браузере и повторите ту же команду. Не удаляйте `archive.sqlite3` и каталог `eml` между запусками.

Дополнительные параметры:

```text
--limit N       Размер страницы списка (по умолчанию 50; максимум 100)
--delay SEC     Пауза между запросами (по умолчанию 0.25 секунды)
--headless      Запуск без окна браузера; используйте только после отдельной проверки авторизации
--max-threads N Ограничение числа переписок для теста
--max-messages N Ограничение числа новых писем для теста
```

### Структура архива

```text
C:\MailArchive\user\
  archive.sqlite3       индекс и состояние выгрузки
  archive.sqlite3-wal   служебный файл SQLite во время работы (может появляться)
  browser-profile\      локальный профиль Chromium с авторизацией
  eml\                  оригиналы писем, разложенные по папкам
  mbox\                 MBOX-файлы для почтового клиента
  logs\archive.log      журнал работы
```

Имена папок получают суффикс с ID VK, чтобы избежать совпадений одинаковых названий.

### Импорт в Thunderbird

1. Дождитесь завершения выгрузки или остановите её штатно `Ctrl+C`.
2. В Thunderbird откройте контекстное меню **«Локальные папки»**.
3. Выберите **ImportExportTools NG → Импорт файлов mbox → Все файлы mbox из каталога (со структурой sbd)**.
4. Укажите `C:\MailArchive\user\mbox`.

MBOX — рабочая копия для просмотра в Thunderbird. Каталог `eml` сохраняйте как исходный архив. После дальнейшей выгрузки MBOX-файлы пересобираются из сохранённых EML; повторный импорт в Thunderbird может создать дубликаты, поэтому финальный импорт лучше выполнять после завершения загрузки.

### Ограничения и известные особенности

- Проект неофициальный и зависит от внутренних API веб-клиента VK WorkSpace/Mail.ru. Совместимость с будущими версиями сервиса не гарантируется.
- Проверялся на конкретном типе корпоративного почтового ящика; поведение других тарифов и конфигураций может отличаться.
- Экспорт выполняется по папкам, возвращаемым API. Счётчики в интерфейсе и фактически доступные сообщения могут различаться.
- Вложения отдельно не скачиваются: сохраняется оригинальное MIME-письмо EML, в котором обычно содержатся вложения. Проверяйте несколько писем с вложениями после экспорта.
- При длительной выгрузке сессия может истечь. Повторный запуск с тем же каталогом продолжает работу с учётом SQLite.
- Не запускайте одновременно несколько копий загрузчика для одного ящика и одного каталога архива.
- Перед удалением исходного почтового ящика самостоятельно проверьте полноту архива, вложения и открытие писем в почтовом клиенте.

### Безопасность и конфиденциальность

- Авторизация выполняется пользователем непосредственно в браузере на своём компьютере.
- Данные писем, EML, SQLite, профиль браузера и журналы остаются локально. Проект не отправляет архив на сторонний сервер.
- Каталог `browser-profile` содержит активную браузерную сессию. Не публикуйте его, не отправляйте третьим лицам и не добавляйте в Git.
- Не публикуйте HAR-файлы, cookies, access tokens, CSRF-токены, EML, SQLite или журналы с личными данными.
- Используйте инструмент только для почтовых ящиков, к которым у вас есть законный доступ и право на экспорт.

Сообщения об уязвимостях: см. [SECURITY.md](SECURITY.md).

## English

A local backup and migration utility for VK WorkSpace / Mail.ru mailboxes. It uses a user-authenticated browser session, downloads original RFC 822 messages as `.eml`, maintains a SQLite resume index, and builds per-folder MBOX files for Thunderbird.

This is an experimental, unofficial integration based on webmail endpoints that may change at any time. The user authenticates locally; mail data and browser session data are stored on the user's computer. Do not share browser profiles, HAR files, tokens, cookies, EML files, or database files.

See the Russian section above for installation, commands, Thunderbird import steps, limitations, and security guidance. The command-line interface and current tested workflow are Windows-oriented.
