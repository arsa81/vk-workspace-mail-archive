# Security Policy

## Reporting a vulnerability

Please do not publish access tokens, cookies, HAR files, mailbox contents, EML files, SQLite databases, or browser profiles in an issue.

For a suspected vulnerability in this project, open a GitHub issue with a minimal description that contains no personal or authentication data. For sensitive reports, contact the repository maintainer privately through the contact method listed on the GitHub profile.

## Handling mailbox data

The application works with private mailbox contents and an authenticated browser profile. Treat the output directory as sensitive. Do not upload it to public issue trackers or commit it to source control.

## Supported versions

Security fixes are provided for the latest published release where practical. This project is experimental and is provided without a service-level guarantee.
